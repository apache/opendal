Detailed Description

An opaque, thread-safe token used to cancel in-flight OpenDAL operations.

Pass a token created with opendal_cancel_token_new() to any *_with_cancel function. Calling opendal_cancel_token_cancel() from another thread wakes waiting operations and causes them to drop their in-flight work and return OPENDAL_CANCELLED.

A single token may be shared across multiple concurrent operations, and cancelling it is idempotent. Free the token with opendal_cancel_token_free() only after all operations using it have returned.
