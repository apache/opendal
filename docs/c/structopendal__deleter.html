Detailed Description

opendal_deleter removes many paths from storage.

Uses batch deletion when the service supports it. Submitting paths can delete them immediately or trigger a batch. Call opendal_deleter_flush to wait for any pending deletions to complete.

The handle stays usable after a flush. On a batch flush failure, pending paths remain queued for another flush.

Construct a deleter with opendal_operator_deleter and release it with opendal_deleter_free. Calls using the same handle must not overlap.
