Detailed Description

The operations and constraints supported by an Operator.

Size limit fields are zero when the operator does not define a limit.

These flags describe the underlying OpenDAL operator. A flag can be true even when the C++ binding does not expose the matching method (for example, restore).

Members that existed before this class was generated come first, in their original order, so positional brace-initialization keeps its meaning. Newer members are appended at the end in a fixed order.
