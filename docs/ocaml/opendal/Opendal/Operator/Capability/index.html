Capability Checking

Module for checking what operations are supported by the storage backend.

Checks for the operations supported by the storage backend.

Size limit accessors return None when the operator does not define a limit.

These flags describe the underlying OpenDAL operator. A flag can be true even when the OCaml binding does not expose the matching function (for example, restore).

val write_with_checksum : Opendal_core.Operator.capability -> bool

Indicates if non-append writes support native verification with a checksum algorithm selected by the service. Verification may cover only individual upload requests, parts, or blocks. Support for caller-selected algorithms and full-object verification depends on the service and write mode. OpenDAL rejects unsupported explicit checksum requests before performing I/O.

val write_multi_max_size : Opendal_core.Operator.capability -> int64 option

Maximum size supported for multipart uploads. For example, AWS S3 supports up to 5GiB per part in multipart uploads.

val write_multi_min_size : Opendal_core.Operator.capability -> int64 option

Minimum size required for multipart uploads (except for the last part). For example, AWS S3 requires at least 5MiB per part.

val write_total_max_size : Opendal_core.Operator.capability -> int64 option

Maximum total size supported for write operations. For example, Cloudflare D1 has a 1MB total size limit.
