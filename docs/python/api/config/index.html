Config#

Use a typed configuration to construct an Operator or AsyncOperator. The service config’s scheme selects the storage service. Use context for per-operator HTTP settings and layers to apply declarative layers in order.

from datetime import timedelta

from opendal import Operator
from opendal.config import ContextConfig, HttpContextConfig, RetryLayerConfig, S3Config

op = Operator.from_config(
    S3Config(scheme="s3", bucket="my-bucket"),
    context=ContextConfig(http=HttpContextConfig(connect_timeout=timedelta(seconds=5))),
    layers=[RetryLayerConfig(name="retry", max_times=3)],
)

Typed operator configurations.

Each service configuration is a TypedDict with a Literal scheme key. A static type checker detects an incorrect scheme, missing required keys, unknown keys, and incorrect value types.

Build a config with the call form or an annotated variable, then pass it to Operator.from_config / AsyncOperator.from_config:

from opendal import Operator
from opendal.config import S3Config

op = Operator.from_config(S3Config(scheme="s3", bucket="b"))

config: S3Config = {"scheme": "s3", "bucket": "b"}
op = Operator.from_config(config)

ServiceConfig is the discriminated union of all service config dictionaries.

Use context=ContextConfig(http=HttpContextConfig(…)) for per-operator HTTP settings and layers= for a sequence of LayerConfig dictionaries applied in the given order.
