open(path: str | os.PathLike[str], mode: str, **kwargs: Unpack[OpenKwargs])#

Open a file-like object for the given path.

The returned file is a context manager and reads or writes bytes. Use read() to supply response header overrides when reading.

Parameters:
pathstr

The path to the file.

modestr

“r” to read, “w” to write (overwrite by default), “a” to append, or “x” to create a new file. An optional “b” can appear before or after the letter. All supported modes are binary; text modes such as “rt” raise ValueError. Wrap the returned file with io.TextIOWrapper to read or write text.

**kwargs

Additional options for the underlying reader or writer. In write and create modes, checksum selects the ChecksumAlgorithm the service uses to verify the full object before committing. Omit checksum or pass None to use the service default.

Returns:
File

A file-like object.

Raises:
TypeError

If **kwargs contains an unknown keyword argument, an option with a non-None value that does not apply to mode, or a value with an incompatible type.

ValueError

If the mode is invalid or unsupported, including text (“t”) and update (“+”) modes, or if the mode conflicts with append or if_not_exists in **kwargs, or if the checksum name is unrecognized.

ConditionNotMatch

If create mode (“x”) targets an existing file. The failure can surface from write(), flush(), or close().

Unsupported

If the service does not support the requested write options, including the selected checksum algorithm. Append writes cannot request a checksum.

ChecksumMismatch

If the checksum fails verification. The failure can surface from write(), flush(), or close().

delete_many(paths)#

Delete an explicit collection of paths with default delete options.

Parameters:
pathsIterable[str | PathLike[str]]

The paths to delete. A single path is not accepted.

Notes

This method collects the iterable and converts its Python path objects before deletion starts, using memory proportional to the number of paths. Empty collections do nothing. Paths that do not exist are ignored. Storage or path-validation errors can leave some paths deleted; this operation is not atomic and does not guarantee a single remote request. Use remove_all to recursively delete a path prefix.

classmethod from_config(config, *, context=None, layers=None)#

Create a new blocking Operator from typed configuration.

A static type checker validates the service scheme and the options for the service, context, and layers. The binding converts non-string values such as booleans, integers, finite floats, durations, paths, and flat lists or tuples to the strings the registry consumes. For a service option that takes a map, such as S3Config.assume_role_session_tags, a dict with str keys and values becomes a JSON object string. A dict for any other option, and values such as bytes, other mappings, and nested sequences, raise Unsupported.

Construction options are stored when pickling the operator and may include credentials. Reapply layers added via .layer() after unpickling.

Parameters:
configServiceConfig

A service configuration such as opendal.config.S3Config.

contextContextConfig | None

Optional per-operator runtime settings, such as an HTTP proxy.

layersSequence[LayerConfig] | None

Optional declarative layers, applied in sequence order.

Returns:
Operator

The new operator.

Examples

import opendal
from opendal.config import S3Config

op = opendal.Operator.from_config(
    S3Config(scheme="s3", bucket="my-bucket")
)
classmethod from_uri(uri, **kwargs)#

Create a new blocking Operator from a URI string.

The URI encodes the scheme and configuration in a single string, e.g. memory:// or s3://bucket/path?region=us-east-1. The scheme must belong to a service enabled in this build. Encode service options as query parameters; use urllib.parse.urlencode when building the URI dynamically.

Parameters:
uristr

The URI of the service, including any options as query parameters.

**kwargsdict

Overrides for URI options. Prefer the URI query string.

Returns:
Operator

The new operator.

Examples

from urllib.parse import urlencode
import opendal

op = opendal.Operator.from_uri("memory://")
query = urlencode({"region": "us-east-1"})
op = opendal.Operator.from_uri(f"s3://bucket/path?{query}")

Get a stored checksum#

With a version-aware service, pass the object version ID v to request the full-object checksum for that version.

stored = op.stat(key, version=v, checksum=True).checksum
if stored is not None:
    algorithm, digest = stored

The digest contains raw bytes. The property is None if the service does not provide a full-object checksum. stat does not read the object data to obtain it.
