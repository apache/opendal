pub fn checksum(self, checksum: impl Into<WriteChecksum>) -> Self

Request native checksum verification for this write.

Pass a WriteChecksum, a crate::ChecksumAlgo to compute, or a caller-supplied crate::Checksum to verify. Refer to options::WriteOptions::checksum for the full contract.

§Example
use opendal_core::Checksum;
use opendal_core::ChecksumAlgo;

let meta = op
    .write_with("path/to/file", vec![0; 4096])
    .checksum(Checksum::new(ChecksumAlgo::Crc32c, crc32c))
    .await?;
assert_eq!(meta.checksum().map(|c| c.algo), Some(ChecksumAlgo::Crc32c));

pub fn expires(self, expires: Duration) -> Self

Sets how long the new file lives after the write commits.

The duration overrides the service’s default TTL and requires crate::Capability::write_with_expires. The write returns crate::ErrorKind::Unsupported without that capability or crate::ErrorKind::ConfigInvalid for a zero or unrepresentable duration.
