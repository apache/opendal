pub fn register_http_context(registry: &OperatorRegistry)
Expand description

Register the reqwest factory for context.http.* operator options.

This replaces any existing http context factory in the registry. When [OperatorRegistry::load] supplies at least one recognized option and validation succeeds, the factory builds a client for the base context. The client uses reqwest’s defaults for omitted fields, including TLS selection. If the scope is omitted or contains only unknown options, the operator keeps its incoming HTTP transport.

Option under context.http.Value
proxyAbsolute HTTP or HTTPS proxy URL with a host. An explicit proxy disables reqwest’s automatic system proxy selection.
no_proxyComma-separated bypass list for the explicit proxy. Requires proxy and at least one nonblank entry.
connect_timeoutDeadline for the connection phase.
read_timeoutDeadline for each read, reset after a successful read.
timeoutTotal request deadline through the end of the response body.
user_agentDefault User-Agent header value. On Wasm, the host Fetch API controls whether it is sent.

All three timeout fields require a positive duration such as 500ms or PT5S.

§Errors

Errors surface when loading an operator. Empty strings for recognized options and invalid values for supported options return [ErrorKind::ConfigInvalid]. A SOCKS proxy URL returns [ErrorKind::Unsupported]. On Wasm, nonempty proxy, bypass, and timeout options return [ErrorKind::Unsupported]. A reqwest client build error returns [ErrorKind::Unexpected].
