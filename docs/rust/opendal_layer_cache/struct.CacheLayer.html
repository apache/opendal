Expand description

Cache aligned source read chunks in another OpenDAL operator.

The default chunk size is 1 MiB, capped by the cache operator’s advertised maximum total write size. The default metadata TTL is 60 seconds. Use a cache backend with capacity eviction to reclaim chunks from old object identities. Use separate cache roots or instances for different tenants, endpoints, or credentials because fresh cache hits skip source I/O.

Add source retry layers before this layer so they retry individual source requests. If a cached stream detects that the source changed after yielding bytes, restart the whole read and discard the partial result.

Sources must expose a verifiable identity (an immutable version other than "null", a strong etag, or last_modified + content_length) to be cached; reads without one pass through to the source. When a source exposes only last_modified and content_length, equal-length overwrites within the backend’s timestamp resolution (such as 1-second mtime granularity) can keep the same identity and serve cached chunks across ttl boundaries.

Single-path mutations invalidate cached metadata for affected paths on completion. Reads explicitly selecting a non-immutable placeholder version such as "null" bypass the cache so local and external overwrites remain visible. For unversioned reads, external writes, recursive deletes, cancelled mutations, and cross-instance read/write races are bounded by ttl (subject to weak last_modified granularity above). Reads selecting an explicit immutable version skip ttl revalidation once cached until invalidated or evicted, even if the version is deleted externally. A reused Reader caches its resolved metadata pointer locally for up to min(ttl, 1s) across range reads, so completed cross-instance invalidations become visible to an already-reused Reader within min(ttl, 1s) and immediately to a newly opened Reader (or immediately when ttl is Duration::ZERO).

pub fn new(cache: Operator) -> Result<Self>

Create a layer backed by cache.

Returns [ErrorKind::ConfigInvalid] if the cache operator’s full capabilities do not include read, write, and delete, or if its advertised maximum total write size is zero.

Source

pub fn with_chunk_size(self, size: usize) -> Self

Set the aligned chunk size in bytes.

Zero restores the default of 1 MiB. Positive sizes are used without rounding. The cache operator’s advertised maximum total write size caps both the default and explicit sizes.

Source

pub fn with_ttl(self, ttl: Duration) -> Self

Set the default metadata freshness window.

Duration::ZERO revalidates before serving a reader. Duration::MAX disables periodic revalidation. Reads of an explicitly selected immutable version skip periodic revalidation regardless of TTL.

Source

pub fn with_policy(self, policy: impl CachePolicy) -> Self

Set a custom per-read admission and TTL policy.

The default policy returns CacheDecision::Cache for all reads.
