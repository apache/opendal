Struct HedgeLayer 

Source 
pub struct HedgeLayer { /* private fields */ }
Expand description

Issues duplicate attempts for slow stat and read requests.

By default the layer hedges both operations after five seconds, with at most one additional attempt per request. Use Self::with_max_hedges to change the limit or set it to zero to disable hedging and its timers. Use Self::without_stat_hedge or Self::without_read_hedge to disable hedging for a single operation. Enabled operations use the Tokio time driver.

A success or an error for which [Error::is_temporary] is false ends the race immediately. A temporary error stops new attempts and lets any attempts already in flight finish. If they all fail temporarily, the layer returns the last observed error. If the primary fails before a hedge is in flight, the layer returns that error immediately.

Each read races the range I/O, including opening a stream. The caller receives the winning response and stream together, and consumes that stream without hedging its chunks. The layer drops pending attempts when it returns or when the caller cancels the operation. Dropping a client-side future may leave the service processing an already submitted request.

Add this layer before the timeout and retry layers. The timeout then covers the whole race, and the outer retry layer can retry a temporary error from it.

use std::time::Duration;

use opendal_core::{Operator, Result, services};
use opendal_layer_hedge::HedgeLayer;
use opendal_layer_retry::RetryLayer;
use opendal_layer_timeout::TimeoutLayer;

fn build_operator() -> Result<Operator> {
    Ok(Operator::new(services::Memory::default())?
        .layer(HedgeLayer::new().with_delay(Duration::from_millis(500)))
        .layer(TimeoutLayer::new())
        .layer(RetryLayer::new()))
}
