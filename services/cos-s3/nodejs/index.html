Full reference
import { Operator } from "opendal";

const operator = new Operator("cos-s3", {
  // --- General ---
  // Root within the bucket. The default is `/`.
  // root: "/",

  // Full COS bucket name including the numeric `APPID` suffix.
  bucket: "example-bucket-1250000000",

  // COS bucket region. Also used to sign requests.
  region: "ap-guangzhou",

  // HTTP(S) base endpoint override.
  // endpoint: "https://cos.ap-guangzhou.myqcloud.com",
  // --- Credentials ---
  // Tencent Cloud `SecretId`.
  // access_key_id: "...",

  // Tencent Cloud `SecretKey`.
  // secret_access_key: "...",

  // Session token for temporary credentials. Requires both keys.
  // session_token: "...",

  // Disable loading credentials from AWS environment variables and shared profile files.
  //
  // Set both `access_key_id` and `secret_access_key` when enabled.
  // disable_config_load: "false",
});

Every option is passed as a string key; OpenDAL parses it into the right type. For a map option, pass a string containing a JSON object whose values are strings, such as {"key":"value"}. Some services may require building the binding with the matching services-* feature enabled.
